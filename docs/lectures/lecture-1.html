01 · The task

Input text, output a finite set of labels

A classifier receives an input x, such as a sentence or document, and predicts one label y from a known set C. Binary classification has two choices; multiclass classification chooses among more. Sentiment, topic, intent, and named-entity type are examples.

Input

A sequence of tokens or a document.

Label set C

For example, {positive, negative}.

Prediction

Choose a label that best fits the evidence.

Why language is hard: the same words can support different meanings depending on syntax, context, and situation. “How can you not love it?” and “You should not love it” share many words but express different sentiment. A bag of isolated word counts can miss this structure.
02 · Represent the text

Bag of words: simple, useful, and blind to order

A feature map φ(x) converts variable-length text into a fixed-length numeric vector. A unigram vocabulary of size |V| gives each word its own coordinate. A document vector counts or marks which vocabulary words appear. The representation is sparse because most entries are zero.

A plain bag has no positions, order, or word-to-word similarity. Word “car” and “truck” are as unrelated as “car” and “taco” in one-hot space.

A richer model learns a vector representation from data rather than requiring every useful feature combination to be written by hand. Neural networks are one way to learn these intermediate features.

03 · Logistic regression

Turn feature-weighted evidence into probabilities

Each feature has a weight. Positive weights support a class; negative weights argue against it. The dot product is a score. For two classes, the sigmoid maps the score to a number from 0 to 1. For multiple classes, softmax makes normalized class probabilities.

Many classes: softmax

Softmax exponentiates each class score and divides by the total. Scores compete: increasing one score takes probability mass from others.

A probabilistic classifier gives confidence estimates, not only a hard label.

04 · Learning from examples

Loss says how wrong; gradient says which way to move

Training chooses weights that give high probability to the correct labels. Negative log-likelihood (equivalently cross-entropy for a classification target) penalizes the model when the true class receives low probability. Gradient descent repeatedly nudges parameters downhill.

Learning rate η

Controls step size. Too small means slow progress. Too large can jump across the minimum or diverge.

Training vs. held-out data

Train weights on training data, make choices on development data, report final performance on test data. Test data should not tune the model.

Overfitting: a model can memorize training examples but fail on new ones. L2 regularization adds a penalty on large weights; simpler solutions often generalize better.

Logistic regression with the usual negative log-likelihood is a convex optimization problem: any local minimum is global. Deep neural networks generally lose this convex guarantee.

Evaluate the decision

Accuracy is not the whole story

Counts of true/false positives and negatives clarify which mistakes a model makes. For cancer screening, missing a true positive can be costly; for a spam filter, false positives may hide wanted messages.

05 · A different linear learner

Perceptron: correct the mistake directly

The perceptron predicts from the sign of a score. If its prediction is right, it does nothing. If wrong, it moves the weight vector toward the true example and away from the mistaken class. Unlike logistic regression, it does not model calibrated probabilities or minimize negative log-likelihood. If data are linearly separable, perceptron training converges to a separating solution.

Logistic regression asks “how probable is each label?” The perceptron asks “which side of the boundary?” The distinction matters when confidence and a smooth loss are useful.
06 · Learn nonlinear features

Hidden layers build combinations a linear model cannot

Suppose a positive review depends on the combination “contains not and contains good.” A linear bag-of-words model adds independent word contributions; it struggles to express such conjunctions and XOR-like patterns. Revision check

Explain it without the slide

Why can’t a unigram bag distinguish “dog bites person” from “person bites dog”?

Both contain the same words with the same counts. The representation has discarded word order and syntactic roles.

What does the sigmoid output mean?

For binary logistic regression it is the estimated probability of the positive class given the input and parameters.

How does gradient descent use the learning rate?

It scales the negative gradient direction. Large η makes larger parameter moves; very large steps can overshoot or diverge.

What does an activation add to a neural network?

Nonlinearity. Without it, any stack of linear layers collapses to a single linear map and cannot learn nonlinear decision boundaries.

Why separate development and test data?

Development data guides model choices. Test data is kept untouched until final evaluation, so it gives a less biased estimate of generalization.

When can recall matter more than precision?

When missing a positive case is especially costly, such as an initial medical screening. A follow-up test may handle false alarms.
