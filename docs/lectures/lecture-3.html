Language unfolds over time: a word’s role and meaning often depend on neighbors. Sequence models carry context from one step to the next, or assign probability to each next token using everything observed so far.

01 · Predict a label at each position

Sequence labeling reads neighbors to disambiguate

Part-of-speech tagging assigns a category to each token; named-entity recognition marks spans such as people, places, or organizations. The word “back” can be adjective (“back door”), noun (“my back”), adverb (“come back”), or verb (“back the bill”). Local context changes the correct label.

These tasks output a sequence of labels aligned to the input sequence. Language modeling instead predicts tokens themselves and can generate text.

02 · Language modeling

Score a whole sentence as a chain of next-token choices

A language model assigns a probability to a sequence. The chain rule decomposes that probability into a product: first-token probability, then each next token conditioned on all previous tokens. A model can be trained by maximizing these probabilities—or minimizing their negative log.

Language models support generation, speech recognition, translation, dialogue, paraphrase, and other tasks. In speech recognition, acoustic evidence is combined with language-model plausibility to choose likely word sequences.

03 · Bounded context

The Markov assumption: remember only the last k tokens

The full chain rule conditions each next token on every previous token. A k-order Markov model approximates this by retaining only the most recent k tokens. That makes prediction manageable, but dependencies outside the window are invisible.

Small k is efficient and captures local patterns. It struggles with long-distance agreement, topic, and earlier facts. Recurrent models use a hidden state as a compressed summary of the prefix rather than a fixed raw-token window.

04 · Recurrent neural network

Pass a state forward, one token at a time

An RNN repeatedly applies the same transition function to the previous hidden state and current token embedding. The hidden state is the model’s learned summary of what it has read so far. Sharing the same parameters at every time step handles sequences of varying lengths.

Transducer

Emit a label/output at every input position: POS tagging, NER, language modeling.

Acceptor / encoder

Use a final or pooled hidden state for one sequence-level decision, such as sentiment.

Generation

Map each state to a next-token distribution, sample/choose a token, feed it back.

RNN computation is sequential: hₜ depends on hₜ₋₁, so the chain of steps limits parallelism. Long sequences can also make it difficult for information and gradients to travel far through many transitions.

Training a recurrent language model

Teacher forcing supplies the real previous token

During training, the model sees a gold prefix and predicts the next token at every time step. The loss is the sum or mean of token-level cross-entropies. This is efficient and gives the model the correct context, but at generation time it must condition on its own sampled tokens instead.

Exposure mismatch: a small generation error changes the next context. Training only on perfect prefixes may not prepare the model for its own mistakes.
05 · Sequence-to-sequence generation

Encode one sequence; decode another

Seq2Seq maps a variable-length input to a variable-length output, for example translating “the movie was great” into “le film était bon.” An encoder reads the source and produces a representation; a decoder generates target tokens, often ending with a STOP token.

Revision check

Can you explain what the hidden state remembers?

How does a language model assign a sentence probability?

Apply the chain rule: multiply each token’s conditional probability given the prefix.

What does the Markov assumption simplify?

It limits the history used for prediction to the previous k tokens, rather than the entire prefix.

What is hₜ in an RNN?

A learned hidden summary produced from hₜ₋₁ and the current input embedding eₜ.

Why can an RNN process variable-length inputs?

The same recurrent transition is applied at every time step, and the sequence may contain any number of steps.

What is a transducer compared with an encoder?

A transducer emits outputs at positions; an encoder/acceptor summarizes a sequence for a sequence-level output.

Why use scheduled sampling?

To expose the decoder during training to its own imperfect prior outputs, reducing the gap from teacher-forced training to generation.
